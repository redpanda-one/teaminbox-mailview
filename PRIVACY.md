# Privacy Policy — TeamInbox MailView

Effective date: 30 September 2026

TeamInbox MailView is developed and published by RedPandaOne.

## Summary

TeamInbox MailView does not collect, transmit, sell, share, or monetize personal data or email content.

## Data collection

RedPandaOne does not collect through TeamInbox MailView:

- email bodies or thread content;
- email subjects;
- sender or recipient information;
- attachments;
- TeamInbox tags, assignments, comments, or other workspace content;
- authentication credentials, cookies, or session tokens;
- browsing history;
- clipboard contents;
- analytics or telemetry.

## Local data

The extension stores one user-interface preference locally in Chrome: the selected preview-pane width. This value contains no email or TeamInbox content.

## Network communication

TeamInbox MailView contains no analytics service, telemetry service, advertising SDK, RedPandaOne API integration, or other RedPandaOne-operated data endpoint.

The Zoho TeamInbox website itself continues to communicate with Zoho services as required for TeamInbox to function. Those communications are part of Zoho TeamInbox, not data collection performed by TeamInbox MailView.

## Page access

The extension runs only on `https://teaminbox.zoho.com/*`. Access is required to alter the page layout and respond to interface actions. Although a browser content script running on a page can technically interact with that page's DOM, TeamInbox MailView is designed only to identify and adjust interface containers and controls. It does not intentionally read, extract, retain, or transmit the textual content of messages.

## Third parties

TeamInbox MailView does not send TeamInbox data to RedPandaOne or to third-party analytics, advertising, AI, or telemetry providers.

## Source review

The extension source is distributed unobfuscated so its behavior can be reviewed. Publishing the source repository does not grant redistribution or commercial-use rights unless RedPandaOne provides them separately.

## Changes

If a future version introduces any feature that requires additional data access or network communication, this policy and the extension permissions must be updated before that feature is released.
